# 🃏 Poker AI Assistant

> *Because winning isn't just luck — it's math.*

A personal project leveraging data-driven analysis and machine 
learning to improve poker decision-making, one hand at a time.

---

## 🎯 Overview

This project is built in two phases:

### Phase 1 — Hand Equity Calculator 🧮
A tool that calculates the **winning probability** of any given 
hand against a range of opponent hands, based on current board 
state and remaining deck composition.

### Phase 2 — Opponent Behavior Analysis 🤖
A machine learning model that infers likely **opponent hand ranges**
by analyzing their betting patterns and in-game actions — enabling 
smarter, more informed decisions at the table.

---

## 🚀 Goals

- ♠️ Apply probability theory and combinatorics to real-time poker scenarios
- ♥️ Develop a predictive model trained on opponent action data  
- ♦️ Build a practical tool that bridges statistical analysis with gameplay strategy
